# Better Minalabac

A community-run portal for **Minalabac, Camarines Sur**: municipal officials, offices, services and public information in one place.

Better Minalabac is a volunteer project listed in the [BetterGov.ph LGU Directory](https://lgu.bettergov.ph/). It is **not** an official website of the Municipality of Minalabac.

## About Minalabac

Minalabac is a coastal municipality in Camarines Sur in the Bicol Region, about 6 kilometers south of Naga City, with a coastline on Ragay Gulf. Most of its land is used for rice, vegetables and root crops, and it is known for its beaches in barangays Bagolatao and Hamoraon.

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

Site content lives in `content/` (Markdown and YAML) and `src/data/`. See [CONTENT-MANAGEMENT.md](CONTENT-MANAGEMENT.md) for how to edit pages without touching code.

## Contributing

Many service pages are still placeholders. If you know how a service works in Minalabac (requirements, office, fees, schedule), open an issue or a pull request. Please cite a public source for facts about officials, offices and fees.
